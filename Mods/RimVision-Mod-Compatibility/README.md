# RimVision – Mod Compatibility

Единый отдельный аддон для совместимости RimVision с небольшими сторонними модами.
Поддерживается `[NL] Facial Animation - WIP` (`Nals.FacialAnimation`), версия для RimWorld 1.6.
Мимика обновляется на текущей текстуре пешки в 3D, включая спящих и переносимых пешек.
Обновление выполняется раз в 3 игровых тика, максимум 30 раз в секунду реального времени;
на паузе анимация не продвигается. Меши, маски выбора и неиспользуемые направления
не пересоздаются. При захвате сохраняется состояние `Rand`.
Поддержка включается только при активном Facial Animation; его DLL и ресурсы
не входят в пакет, а обязательная зависимость на него не добавляется.
Multiplayer-аддон остаётся отдельным модом.

Поддерживается также `Interaction Bubbles` (`Jaxe.Bubbles`), установленная версия 4.2
для RimWorld 1.6. Облачка рисуются поверх окна 3D над видимыми пешками; проекция
и проверка стен используют существующий код RimVision. Облачка за камерой,
в тумане войны и за стенами скрываются. В первом лице облачка управляемой пешки
не рисуются. Масштаб и предел удаления камеры учитывают высоту 3D-камеры;
текст, цвета, смещения, срок жизни и фильтры остаются штатными для Interaction Bubbles.
В обычном 2D используется прежняя отрисовка. Поддержка активируется только при
наличии мода, его DLL и ресурсы в пакет не копируются.

## Сборка и установка

В Unity Editor:
- `RimVision > Mod compatibility > Build addon (DLL + ZIP)`.
- `RimVision > Mod compatibility > Build and install addon in RimWorld`.

Результат: `Build/RimVision-Mod-Compatibility` и
`Build/RimVision-Mod-Compatibility.zip`. Лог: `Build/ModCompatibility.log`.
Путь игры задаётся через `RimVision > Choose RimWorld folder`.
Нужны установленный .NET SDK, RimWorld и HarmonyMod.
Установка сохраняет предыдущий пакет в `Backups`; после обновления перезапустите игру.

Сборка аддона независима от пункта включения Multiplayer и не требует Multiplayer API
или сборки шейдеров. Обычные команды сборки RimVision этот аддон не включают.
Основной проект компилируется как зависимость; в пакет аддона входит только
`Recovery.Rim3D.Compatibility.dll`, без основной DLL и библиотек игры.
Сам RimVision должен быть собран и установлен отдельно.

Исходники находятся в `Source/Compatibility/Source`, метаданные –  в `About/About.xml`.
DLL предназначена для RimWorld; сборка не импортирует её в Unity Editor.

## Подключение

Порядок загрузки: Harmony → Core и DLC → поддерживаемые сторонние моды → RimVision → RimVision – Mod Compatibility.
Настройки включения мимики, категорий пешек и отрисовки лица остаются за Facial Animation.

Будущую поддержку каждого мода добавляйте в отдельные файлы или папки внутри `Source`.
Патчи должны включаться только при наличии соответствующего мода; порядок загрузки
для него указывается в `loadAfter`. Изменения игрового состояния должны учитывать
синхронизацию Multiplayer. Проверка этой интеграции выполнена статическим чтением
исходников RimVision и IL установленных DLL Facial Animation 1.6 и Interaction Bubbles 4.2. Сборка и игровая
сессия не запускались; работа в игре и Multiplayer не подтверждена.

# Локализация Rim3D

Используется стандартная система переводов RimWorld. Язык выбирается в настройках
игры; отдельного переключателя и загрузчика XML у мода нет. При отсутствии
перевода RimWorld использует английский словарь.

## Структура

- `English/Keyed/Rim3D.xml` –  базовые строки интерфейса.
- `Russian/Keyed/Rim3D.xml` –  русский перевод с теми же ключами.
- `<язык>/DefInjected/JobDef/Rim3D.xml` –  переводы `reportString` заданий.

Подключён весь пользовательский текст игрового Runtime: меню персонажа,
инвентарь, здоровье, строительство, рецепты, контекстные действия, предметы,
статусы, подсказки управления, причины недоступности действий, стрельба и
сообщения Multiplayer. Совместимость использует словарь основного Rim3D,
который является обязательной зависимостью. Собственные JobDef переведены через
DefInjected. Технические логи, имена объектов Unity, идентификаторы, меню
инструментов редактора и статические метаданные About не являются игровыми
строками Keyed. Названия и описания контента RimWorld берутся из игровых Def.

## Добавление строки

1. Добавить одинаковый ключ с префиксом `Rim3D_` в английский и русский XML.
2. В C# с `using Verse;` получить перевод непосредственно при использовании:

```csharp
"Rim3D_Take".Translate().ToString()
"Rim3D_TakeCount".Translate(count, target.stackCount).ToString()
```

Динамические значения передавать параметрами `{0}`, `{1}`, `{2}`. По возможности
переводить целое предложение: переводчик должен иметь возможность менять порядок
слов и значений. Сохранять параметры, игровые обозначения `TargetA` и разметку.
Перенос строки в Keyed записывается как `\n`.

Не переводить `defName`, имена классов, пути ресурсов, названия шейдеров и ключи
сохранений. Названия предметов брать из `LabelCap`, описания –  из игровых Def.
В статических массивах хранить ключи, а перевод получать при отображении:
не сохранять перевод в статическом поле до загрузки языка.

## Новый язык

Скопировать `English` в папку с системным названием языка RimWorld (например,
`German`) и перевести значения XML, сохраняя ключи и структуру. Пересборка DLL
для изменения переводов не нужна; после изменения файлов перезапустить игру.
Обычная сборка через меню Rim3D автоматически включает папку `Languages` в ZIP
и установку мода.

# Сторонние компоненты

Для автономного чтения игровых ресурсов используется [UnityPy](https://github.com/K0lb3/UnityPy), версия 1.20.26.
Оригинальные wheel-архивы включены без изменения. Их файлы лицензий и метаданных сохраняются при распаковке в личный кэш Blender.
Комплект Windows x64 содержит зависимости для CPython 3.11 и 3.13; совместимые abi3 и чистые Python-пакеты используются обеими версиями.

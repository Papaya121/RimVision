# RimVision

RimWorld-мод с 3D-видом, управлением персонажем от первого лица и взаимодействиями с миром.

## Начало работы

- [Сборка, установка и ресурсы](Docs/Development/Build.md) –  зависимости, `Build.bat`, параметры сборки, версия мода и шейдеры.
- [Документация](Docs/README.md) –  механики, API, архитектура и архив.

## Структура репозитория

| Каталог | Содержимое |
| --- | --- |
| `Source/RimVision` | Основной мод и публичный API |
| `Source/Multiplayer`, `Source/Compatibility`, `Source/ThirdPerson` | Отдельные аддоны |
| `Mods` | About, Defs, Languages, модели, текстуры и готовый shader bundle |
| `Shaders` | Исходники шейдеров |
| `Builds` | Собранные папки модов и ZIP; прежние локальные артефакты –  в `Builds/Legacy` |
| `Docs` | Документация проекта |
| `Tools/Blender` | Blender-плагин, зависимости и упаковщик |
| `Tools/Models` | Генераторы моделей и XML LOD |

`Version.txt` задаёт отображаемую версию основного мода и Multiplayer-аддона при сборке. Это отдельная версия от публичного API и версий DLL.

# Модели объектов DLC из IsoRim

Источник: локальный пакет Steam Workshop `294100/3819577715` (порт IsoRim для
RimWorld 1.7). Геометрия OBJ преобразована в штатный XML-формат RimVision;
зависимости от DLL, Defs и шейдеров IsoRim нет. Лицензия и авторство сохранены
в соседнем `LICENSE`. Исходный проект: https://github.com/kndzio/IsoRim.

Добавлены модели для 67 ThingDef: Anomaly — 33, Odyssey — 31, Royalty — 2,
Ideology — 1. Для Biotech подходящие модели уже присутствовали в RimVision.
Имеющиеся модели не заменяются. Core, растения и пни, пешки, механоиды и
животные исключены. SecurityDoor и VacBarrier сохраняют существующие
анимированные модели дверей RimVision.

Составные модели включают дополнительные части в статической позе. Варианты
Graphic_Random сопоставлены именам текстур из манифестов DLC. Для контейнеров
с CompProperties_EmptyStateGraphic добавлены модели открытого состояния через
graphicPathContains. Соединения Fleshmass используют requiredLinks. PitGate
и PitBurrow используют groundCutout для вырезания грунта по контуру отверстия,
как существующие модели могил. Остальные напольные объекты сохраняют прежнюю
отрисовку. Настенные объекты подняты к высоте 1.55 клетки.

Замкнутые части моделей используют отсечение обратных граней, открытые
текстурированные поверхности остаются двусторонними. Перекрывающиеся грани
составных замкнутых частей в одной плоскости обрезаются при импорте; для внешних
совпадающих поверхностей приоритет имеет более поздняя деталь OBJ. Это устраняет
конфликт днищ с грунтом и материалов основания со стенками.

Цвета MTL сохранены в solidColor либо запечены в небольшие текстуры материалов
в `Textures/RimVision/IsoRim`. Части stuff сохраняют tintWithThing; для исходного
шаблона текстуры `{stuff}` используется Metal. Цвета вершин ям запечены в
атласы с градиентами. Динамическая смена фактуры под
материал постройки, анимации, пульсация, свечение по активности и специальные
эффекты IsoRim не переносятся. Модели механик с отдельным состоянием (например,
взломанный стабилизатор) используют основную геометрию, если штатный graphicPath
не меняется. Игровая симуляция и Multiplayer-команды не изменены.

Повторный импорт из корня репозитория (Python 3 и Pillow):

```powershell
python Tools/Models/ImportIsoRimDlc.py <папка-мода-IsoRim> <папка-RimWorld>
```

Скрипт проверяет существующие XML-модели обеих папок OptionalContent и
принадлежность ThingDef к DLC с учётом наследования игровых определений.
Обобщённые категории и fallback-модели IsoRim для Core не импортируются.
Build.ps1 упаковывает эти ресурсы и создаёт LOD штатным способом.
